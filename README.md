# EduAI: Your Smart Study Companion

Build a professional education web application called "EduAI".

The platform is an AI-powered study assistant designed for school and high-school students worldwide.

The main goal is to help students learn their complete syllabus through AI tutoring, lessons, notes, quizzes, practice questions, flashcards, study plans, revision and progress tracking.

Target users:

- School students

- High-school students

- Students preparing for board examinations

The platform must be designed to support multiple countries, education systems, boards, grades/classes and subjects.

For the initial version, create the complete responsive application structure and professional UI.

Main navigation:

1. Home

2. My Dashboard

3. Learn

4. AI Tutor

5. Study Planner

6. Practice

7. Progress

8. Profile

Create a modern, clean, student-friendly interface.

The homepage should contain:

- Hero section

- "Start Learning" button

- "Ask AI Tutor" button

- Subject cards

- How it works

- Features

- Student progress concept

- Testimonials section

- Footer

Do NOT hard-code the application around only one country, board or class.

The architecture must be scalable so that countries, boards, classes, subjects, chapters and topics can be added later.

Use a clean professional design with responsive layouts for desktop, tablet and mobile.

Do not add fake AI functionality yet.

First create the application structure and UI.
